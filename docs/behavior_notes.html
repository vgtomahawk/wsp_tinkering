How the agents edited Qwen3.5-0.8B

Companion to the results page. Covers: what reader and writer matrices are, how agents worked without activations (zero-shot), how to read the damage (KL) numbers, and how the 10-pass edits varied within and across models. All numbers come from existing runs; protocol v2, neutral prompt. Code and logs: github.com/vgtomahawk/wsp_tinkering (docs/QUALITATIVE.md has more detail).

Background

The model's matrices: readers and writers

Qwen3.5-0.8B has 752M parameters. 254M of them are the token embedding, which is tied to the output layer; agents were not allowed to edit it (nor the final norm). The rest sits in 24 layers (18 Gated DeltaNet linear-attention layers, 6 full-attention layers), which together hold 186 weight matrices (498M weights).

Every token carries a 1,024-number vector through the network, the residual stream. Each layer reads from it and adds its output back. That splits the matrices in two:

KindWhat it doesMatrices in Qwen3.5-0.8BCount
Writersoutput is added to the residual streamattention output (o_proj ×6, DeltaNet out_proj ×18), MLP down_proj ×2448 (138M weights)
Readerstake the (normalized) residual stream as inputattention q/k/v_proj (×6 each), DeltaNet input projections (in_proj_qkv, z, a, b, ×18 each), MLP gate_proj, up_proj (×24 each)138 (359M weights)

Removing a direction d (a 1,024-number unit vector, e.g. "the refusal direction"):

  • Writer edit W ← W − d dᵀW: the matrix can no longer write anything along d. This is the Arditi et al. recipe ("abliteration").
  • Reader edit W ← W − W d dᵀ: the matrix ignores any d component in its input, so the layer cannot react to it even if something else wrote it.

Each such edit is rank 1: it touches every entry of the matrix a little. "% of weights" below is the share of all weight entries whose stored value changed.

a) Zero-shot

Working without activations

The standard recipe reads the refusal direction from activations (run the model on harmful and harmless prompts, take the difference of means). With 0 forward passes that is impossible, so each agent needed a stand-in it could read off the weights.

Opus 5.5 (0.55): reading the wiring diagram

  • Through the output layer, ranked late MLP neurons by which tokens they promote; found an "I" group and a "cannot / unable / 无法" group.
  • Left the "I" group alone (fed by generic first-person neurons; editing it would hurt ordinary text).
  • Found the input direction the "cannot" neurons share ("inability", fed by neurons for "unsafe", "unethical", "inappropriate"), and a second shared direction for "harm".
  • Inferred a chain, harm judged → "cannot" → refusal tokens, and removed both directions from the writers in layers 4–22.

Inkling 2 Small (0.53, 0.62) and GLM 5.3 (0.80, 0.69): an embedding stand-in

  • Directions carrying harm judgement worked; pure refusal wording did not. Qwen's refusals usually start with "I", not "Sorry" or "cannot", so removing the wording axis leaves the decision intact and the model refuses in other words.
  • The stand-in is a weak proxy. The direction that works with passes (read from activations) is nearly orthogonal to every embedding-derived one (overlap 0.10–0.16).
  • Older Inklings (0.77–0.79) picked rows by size or position, not meaning, and scaled them instead of removing a direction: tiny edits, no effect.
  • GLM named the Arditi recipe from memory but could not run it; its run 1 deliberately removed harm content to isolate "the act of refusing", which is the variant that did nothing.

How firm: mechanisms come from the agents' logs and saved edits. The harm-vs-wording pattern rests on five edits noticed after the fact (suggestive). Opus zero-shot is a single run.

b) Damage

How to read KL

KL = first-token KL divergence from the unedited model on 100 harmless prompts: how much the very first word of an ordinary answer shifts. The Arditi recipe's 0.065 is a practical yardstick.

Outer modelZero-shot KL10-pass KL (per run)

GLM 5.30.046, 0.0300.019, 0.10
Older Inklings0.001–0.0210.001–0.009
Arditi et al. recipe–0.065
  • Every agent that removed refusals stays in Arditi's range; over-refusal on harmless prompts stays ≈0 and Alpaca answer loss barely moves (≈2.00–2.03 vs 2.01 unedited).
  • Low KL alone is not good: the older Inklings have the lowest KL because they barely changed anything.
  • Damage trades against suppression within a model: Inkling 2 Small 0.02 refusal at KL 0.086 vs 0.36 at 0.021; GLM 0.24 at 0.019 vs 0.17 at 0.10.
  • With passes, agents spend budget cutting damage: a working edit at pass 1, then KL falls (Opus 0.21 → 0.05, Inkling 2 Small 0.17 → 0.09).

Limits: first-token KL and Alpaca loss only; no broad capability benchmark. Say "low collateral damage on these measures", not "capabilities preserved".

c) 10 forward passes

Same recipe family, different choices

Within a model

  • Opus is the most consistent: two different routes, the same score.
  • GLM varies a little: the narrower edit leaves more refusals but does less damage.
  • Inkling 2 Small varies most. Run 1 tested writers-only (practice refusals 41 → 9 of 64), found it insufficient, and also blocked the readers (41 → 0), checked on three separate practice slices. Run 2 tested a full-network writer edit (KL ≈ 0.16), chose late writers only to limit damage, and knew about 20 of 96 practice requests were still refused.

Across models

  • Opus localizes: it found which layers write the direction for specific requests and edited only those (the most surgical edit).
  • Inkling 2 Small is the only agent to edit readers; that run had the strongest suppression.
  • GLM runs the textbook recipe quickly (≈17 turns per run vs 40–70 for Inkling).
Is Inkling 2 Small's 0.02 real? Valid and reproducible: it is the agent's own final edit, scored afterwards on the held-out set by the same judge as every row; the agent never saw test prompts. Against Arditi's 0.07 it is 2 vs 6 refused prompts out of about 83, within noise, so the fair claim is that it matched the expert recipe, by editing both sides of the residual stream at somewhat higher damage.
Caveats

What these notes do not show

  • 1–2 runs per cell; Opus zero-shot is a single run.
  • Per-pass curves exist for one run each of Opus and Inkling 2 Small only.
  • Damage measured by first-token KL and Alpaca loss only; one small inner model.
  • Agents saw judge verdicts on practice prompts (never the test sets); the Arditi reference uses its usual first-token proxy.
