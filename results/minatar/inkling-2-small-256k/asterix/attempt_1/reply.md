Design: a hand-coded greedy “safe treasure seeker”. The input channels used are 0 player, 1 enemy, 2 treasure; projectiles/gauge are always empty. First hidden layer computes only five signed features: net vertical pull (treasure below minus treasure above, minus 1.3× enemy imbalance), net horizontal pull, left/right edge contact, top/bottom edge contact, and a smooth horizontal center pull. Second hidden layer is a near-pass-through (`tanh(1.5*h1)`), and the output layer converts those features into action logits: move vertically toward safer/treasure-rich rows, horizontally toward safer/treasure-rich columns, away from the outer side edges where entities spawn, always with fire effectively banned and no-op disfavoured. Enemies are weighted somewhat more heavily than treasure for survival.
